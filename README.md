# SmartSpend AI – Intelligent Expense Tracker

SmartSpend AI is a Django-based web application designed to help users manage daily expenses, track budgets, analyze spending patterns, and make smarter financial decisions.

## Features
- User Registration and Authentication
- Expense Management
- Category-wise Expense Tracking
- Monthly Budget Management
- Interactive Analytics Dashboard
- Spending Pattern Analysis
- Machine Learning-based Expense Prediction
- PDF and CSV Reports

## Technology Stack
- Python
- Django
- SQLite
- HTML, CSS, JavaScript
- Bootstrap 5
- Chart.js
- Pandas and Scikit-learn

## Installation

```bash
git clone YOUR_REPOSITORY_URL
cd SmartSpend-AI

python -m venv venv

# Windows
venv\Scripts\activate

pip install -r requirements.txt

python manage.py migrate
python manage.py runserver
```

Open http://127.0.0.1:8000/ in your browser.
